엑셀방송 설정

다수 BJ로 진행되는 방송에서 후원 점수를 자동으로 계산하여 엑셀랭킹(엑셀판)으로 표시할 수 있습니다.

엑셀방송 호스트 설정

엑셀방송 시작 버튼 클릭 시 점수 반영(랭킹)이 시작됩니다.

프로젝트명

종료 타이머

시간
분
초

유의사항

  • [엑셀방송 시작] 클릭 이후 엑셀 점수의 계산이 시작됩니다.
  • 신규 프로젝트 저장을 위해 프로젝트명을 변경해 입력해주세요.
  • 신규 프로젝트 설정 시 현재 설정을 유지할 경우 세팅값은 유지되고 새롭게 후원 내역이 저장됩니다.
  • 기존 프로젝트에서 방송을 시작의 경우 기존 후원 내역이 유지됩니다.
  • 종료 타이머 기능 사용시, 엑셀판에 남은 시간이 표기되며 종료 5분전부터 강조되어 표시됩니다.
  • 엑셀 방송 종료 및 타이머 종료 시간 이후에는 후원 시 점수가 반영되지 않습니다.(엑셀판은 계속 노출)
  • 방송 종료 시 엑셀 방송 기능은 같이 종료됩니다.

    • 참여 호스트 설정

    번호 참여호스트 엑셀표기 직책
    		배경색 이름색 타이머 관리

    유의사항

  • 참여 호스트 설정 이후 하단의 “설정 저장” 버튼을 누른 뒤 적용됩니다.
  • 기여도는 ON/OFF 가능하며, 선택 시 엑셀판의 해당 항목이 미노출됩니다.
  • 직책은 이름앞에 접두사로 표기됩니다.
  • 직책 변경은 렉스 점수 및 기여도에 영향을 주지 않습니다.

    • 랭킹 설정

    구분
    일급계산(%)
    		배경색 이름색

    유의사항

  • 일급은 해당 방송에서 받은 모든 렉스의 합계에서 자동 계산됩니다. 엑셀판에는 금액이 표시됩니다.
  • 일급 퍼센트는 100을 초과할 수 없습니다.

    • 팀 설정

    구분 팀명 팀원선택 MC
    		배경색 이름색 승리색 관리

    유의사항

  • 참여 호스트 설정에서 먼저 저장되지 않은 BJ는 팀원 선택지에 나타나지 않습니다.
  • 팀 설정 이후 하단의 “설정 저장” 버튼을 누른 뒤 적용됩니다.
  • 팀원은 참여 호스트 중 1명으로 선택이 가능하며, 중복으로 선택할 수 없습니다.
  • 팀 배틀제외 선택 시 팀 배틀테마 프리셋에서 제외됩니다.

    • 배틀 설정

    구분 팀명 팀원선택 렉스 기여도 배경색 이름색 승리색 관리

    유의사항

  • 배틀이 종료되면 배틀 종료 버튼을 클릭하여 점수 집계를 중단해 주세요.(카운트가 끝나도 배틀 점수는 누적됩니다.)
  • 2개 이상의 팀을 설정해야 배틀이 표시되며, 팀 추가, 수정 후 설정 저장을 눌러서 저장해 주세요.
  • 배틀을 시작하면 이전 점수는 초기화되고 집계를 다시 시작합니다.
  • BJ는 중복해서 선택할 수 없읍니다.

    • 후원 리스트

    후원일자 후원(아이디/닉네임) 후원렉스 참여호스트 렉스 점수 기여도 관리

    유의사항

  • 후원 리스트는 최신순으로 정렬됩니다.
  • 렉스 점수와 기여도는 렉스 1개당 1점으로 계산됩니다.
  • 후원리스트는 1개월(30일) 동안 저장되며, 이후 삭제됩니다. 내역 보관이 필요의 경우 다운로드하여 관리해주세요.
